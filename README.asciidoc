= Standard Notes Flatpak

This repository contains the Flatpak packaging for https://standardnotes.com[Standard Notes] (`org.standardnotes.standardnotes`).

== Building from Source

Standard Notes is built from upstream Git source tags using Yarn Berry and the Freedesktop Node 22 SDK extension inside an offline sandbox.

=== Prerequisites

Install Flatpak and the Flatpak Builder container:
[source,sh]
----
flatpak install flathub org.flatpak.Builder
flatpak install flathub org.freedesktop.Platform//26.08
flatpak install flathub org.freedesktop.Sdk//26.08
flatpak install flathub org.freedesktop.Sdk.Extension.node22//26.08
----

=== Local Build

Build the package locally using `org.flatpak.Builder`:
[source,sh]
----
flatpak run org.flatpak.Builder build \
  --ccache \
  --disable-updates \
  --force-clean \
  --disable-rofiles-fuse \
  org.standardnotes.standardnotes.yml
----

=== Regenerating Sources Locally

To update `generated-sources.json` against an upstream release lockfile:
[source,sh]
----
# 1. Clone flatpak-builder-tools
git clone --depth=1 https://github.com/flatpak/flatpak-builder-tools.git src/flatpak-node-generator

# 2. Run flatpak-node-generator with electron node headers
flatpak run --filesystem="$(pwd)" \
  --env=PYTHONPATH="$(pwd)/src/flatpak-node-generator/node" \
  --command=python3 org.flatpak.Builder \
  -m flatpak_node_generator \
  --electron-node-headers \
  yarn /path/to/upstream/yarn.lock \
  -o generated-sources.json
----
